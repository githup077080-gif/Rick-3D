# Rick 3D Engine — Starter archive 0.3.0

## موجود در این سورس
- نمایش محیط سه‌بعدی خالی همراه با Grid
- رندر با OpenGL ES 3.0
- افزودن مکعب و کره
- پاک‌کردن اشیای صحنه
- چرخش دوربین با یک انگشت
- زوم با دو انگشت

## نکته درباره شماره نسخه
نام آرشیو 0.3.0 است، اما تنظیمات داخلی برنامه و نوشته‌های رابط کاربری هنوز نسخه 0.2.0 را نشان می‌دهند.

## قابلیت‌هایی که هنوز پیاده‌سازی نشده‌اند
- انتخاب واقعی شیء با لمس
- برجسته‌کردن شیء انتخاب‌شده
- جابه‌جایی، چرخش و تغییر اندازه واقعی اشیا
- ذخیره و بازکردن پروژه
- terrain، فیزیک، نورپردازی پیشرفته و خروجی گرفتن از بازی

دکمه‌های انتخاب/حرکت/چرخش/اندازه در رابط فعلی فقط نمایشی‌اند و ابزار عملیاتی نیستند.

## ساخت
پروژه را در Android Studio باز کن، Gradle Sync انجام بده و از Build > Build APK(s) خروجی بگیر.

**وضعیت آزمایش:** سورس در این محیط کامپایل یا روی گوشی آزمایش نشده است.
