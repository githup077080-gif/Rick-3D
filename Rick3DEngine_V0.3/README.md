# Rick 3D Engine — Starter 0.3.0

## تغییرات نسخه 0.3
- انتخاب تقریبی مکعب/کره با لمس صفحه
- مشخص‌شدن شیء انتخاب‌شده با رنگ متفاوت
- کشیدن شیء انتخاب‌شده برای جابه‌جایی روی صفحه افقی زمین
- حذف شیء انتخاب‌شده
- حفظ کنترل چرخش دوربین و زوم دو انگشتی
- نمایش وضعیت انتخاب در پنل صحنه و بازرس

## ساخت
پروژه را در Android Studio باز کن، Gradle Sync انجام بده و از Build > Build APK(s) خروجی بگیر.

## محدودیت‌های شناخته‌شده
- انتخاب با فاصله صفحه‌ای تقریبی انجام می‌شود و هنوز ray picking دقیق نیست.
- جابه‌جایی، حرکت تقریبی روی صفحه XZ است؛ gizmo محورها هنوز ساخته نشده.
- ابزارهای چرخش و اندازه فعلاً فقط در رابط دیده می‌شوند و عملیات واقعی ندارند.
- ذخیره/بازکردن صحنه، terrain، نورپردازی پیشرفته، فیزیک و خروجی گرفتن از بازی هنوز پیاده‌سازی نشده‌اند.
- سورس در این محیط کامپایل یا روی گوشی آزمایش نشده است.
