# Rick 3D Engine — Version 0.4.0

نسخهٔ چهارم ویرایشگر لمسی Rick 3D Engine.

## امکانات این نسخه
- صحنهٔ سه‌بعدی خالی با Grid
- افزودن مکعب و کره
- انتخاب شیء با لمس نزدیک مرکز آن
- برجسته‌سازی شیء انتخاب‌شده
- ابزار Move: کشیدن انگشت برای جابه‌جایی تقریبی روی صفحهٔ XZ
- ابزار Rotate: کشیدن انگشت برای چرخاندن شیء حول محور Y
- ابزار Scale: کشیدن عمودی انگشت برای تغییر اندازهٔ یکنواخت
- چرخش دوربین با یک انگشت در حالت Select
- زوم با دو انگشت
- حذف شیء انتخاب‌شده و پاک‌کردن صحنه

## ساخت APK
1. پوشهٔ `Rick3DEngine_V0.4` را در Android Studio باز کن.
2. صبر کن تا Gradle Sync تمام شود.
3. از مسیر **Build > Build APK(s)** خروجی بگیر.

## محدودیت‌ها
- انتخاب شیء با فاصلهٔ صفحه‌ای از مرکز آن انجام می‌شود؛ هنوز ray picking دقیق و gizmo سه‌محوره وجود ندارد.
- Move روی صفحهٔ تقریبی XZ انجام می‌شود.
- Rotate فعلاً حول محور Y و Scale یکنواخت است.
- ذخیره/بازکردن پروژه، terrain، فیزیک، انیمیشن، اسکریپت‌نویسی و خروجی بازی هنوز در این نسخه نیستند.
- این سورس در این محیط کامپایل یا روی دستگاه واقعی آزمایش نشده است؛ بنابراین APK آماده و تأییدشده‌ای ارائه نمی‌شود.
