# Rick 3D Engine

پروژهٔ ساخت یک موتور بازی‌سازی سه‌بعدی اختصاصی با ویرایشگر لمسی اندروید.

## نسخهٔ فعال

- **V6.1** — پروژهٔ اصلی اندروید در مسیر [Rick3DEngine_V0.6](./Rick3DEngine_V0.6/)
- [وضعیت پیاده‌سازی و محدودیت‌های V6.1](./Rick3DEngine_V0.6/IMPLEMENTATION_STATUS.md)
- [معماری فنی V6](./docs/V6_TECHNICAL_ARCHITECTURE.md)

نسخهٔ فعال شامل ویرایشگر اولیهٔ OpenGL ES 3.0، افزودن مکعب و کره، ابزارهای پایهٔ تغییر شکل، ذخیره و بازکردن صحنهٔ JSON و Undo/Redo است. این قابلیت‌ها در سورس پیاده‌سازی شده‌اند؛ تا زمانی که GitHub Actions با موفقیت تمام نشود، ساخت APK تأییدشده محسوب نمی‌شود.

## ساخت APK

فایل اصلی ساخت خودکار:
`.github/workflows/rick-v6-android.yml`

این Workflow از JDK 17 و Gradle 8.9 سازگار با Android Gradle Plugin 8.7.3 استفاده می‌کند، فایل‌های ضروری پروژه را بررسی می‌کند، ساخت Debug APK را انجام می‌دهد و در صورت موفقیت فایل APK را به‌صورت Artifact منتشر می‌کند.

[مشاهدهٔ اجرای ساخت در GitHub Actions](https://github.com/githup077080-gif/Rick-3D/actions)
