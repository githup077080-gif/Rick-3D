# Rick 3D Engine — V6 Titan

**نسخهٔ هدف: 0.6.0 | وضعیت: طرح فنی و برنامهٔ پیاده‌سازی**

Rick V6 قرار است ویرایشگر سه‌بعدی لمسی برای اندروید باشد؛ با شروع از یک صحنهٔ خالی و ابزارهایی که روی گوشی‌های معمولی نیز با تنظیم کیفیت اجرا شوند.

> مهم: این پوشه در این مرحله سند طراحی و نقشهٔ توسعه است، نه APK یا ادعای پیاده‌سازی کامل قابلیت‌ها. کد نسخهٔ 0.4.0 مبنای مهاجرت است و قابلیت‌های جدید باید مرحله‌به‌مرحله کدنویسی، کامپایل و آزمایش شوند.

## هدف‌های V6

1. **Viewport واقعی و قابل کنترل:** دوربین orbit/pan/zoom، شبکهٔ اختیاری، نمایش محورهای جهان و حالت‌های نمای روبه‌رو/بالا/کنار.
2. **انتخاب دقیق:** ray picking از مختصات لمس به فضای سه‌بعدی، انتخاب از میان اشیای هم‌پوشان و نمایش انتخاب در Scene Tree.
3. **Gizmo سه‌محوره:** جابه‌جایی روی X/Y/Z، چرخش حول هر محور و تغییر اندازهٔ محوری و یکنواخت؛ با دستگیره‌های بزرگ و مناسب لمس.
4. **Undo/Redo:** تاریخچهٔ فرمان‌ها برای افزودن، حذف و تغییر Transform؛ با محدودیت حافظه و ادغام حرکت‌های پیوسته.
5. **ذخیره و بازکردن پروژه:** قالب نسخه‌دار JSON برای صحنه، شناسهٔ پایدار اشیا، تنظیمات دوربین و فهرست دارایی‌ها؛ استفاده از Android Storage Access Framework.
6. **Inspector کاربردی:** ویرایش عددی Position، Rotation و Scale و نمایش شناسه/نوع شیء انتخاب‌شده.
7. **دارایی‌ها:** واردکردن مدل glTF/GLB و بافت‌ها به‌صورت مرحله‌ای؛ اعتبارسنجی فایل و پیام خطای روشن.
8. **کارایی موبایل:** سطح کیفیت قابل تنظیم، محدودیت حافظهٔ دارایی‌ها، توقف رندر غیرضروری در حالت بیکار و گزارش FPS/زمان فریم.
9. **خروجی بازی:** ابتدا تعریف قالب پروژه و ساخت قابل تکرار؛ سپس APK از طریق Gradle یا Cloud Build. خروجی APK تا زمان تست واقعی، آماده اعلام نمی‌شود.

## معماری پیشنهادی

- Android UI: Kotlin + Jetpack Compose
- Viewport: Android GLSurfaceView + OpenGL ES 3.0 در مرحلهٔ اول
- ریاضی سه‌بعدی: ماتریس‌های view/projection/model و تبدیل ray در فضای محلی
- Scene: مدل دادهٔ مستقل از UI، شناسهٔ پایدار و serialization نسخه‌دار
- Undo/Redo: Command Pattern با فرمان‌های قابل برگشت
- فایل‌ها: Storage Access Framework؛ بدون دسترسی گسترده و غیرضروری به حافظه
- دارایی‌ها: glTF 2.0 / GLB در مرحلهٔ واردسازی
- تست: تست واحد ریاضی و serialization، تست رابط روی اندازه‌های مختلف نمایشگر، تست طولانی‌مدت دما و حافظه
